# Cypress Testing in the AI-Era

Project of the Cypress Testing in the AI Era course from the Talking About Testing online school.

👋 Welcome!

It's great to have you here. I'm sure you will love this course. ❤️

## What will you learn?

- The basics of prompt engineering: LLMs, tools, prompts, skills, agents, agent modes, context windows, token consumption, and hallucinations
- How to install and use the official Cypress skills - cypress-author, cypress-explain, and cypress-docs
- How to write end-to-end tests for a web app with cypress-author
- How to write frontend component tests for EmojiMart's ThankYouPage and SearchBar with cypress-author
- How to write API tests for the EngageSphere REST API with cypress-author
- How to review Cypress code with cypress-explain and cypress-docs
- How to debug failing Cypress tests with cypress-explain and cypress-docs
- How to analyze test gaps and build a ready-to-consume report for cypress-author to implement
